# Identidad visual de ConsultorAI para el hackatón

**Nombre:** ConsultorAI. Elegido al iniciar el hackatón.

**Paleta indicada por Javi el 14 de octubre de 2026:** rojo, gris antracita y blanco.

| Uso | Color |
|---|---|
| Acción principal y acentos | Rojo intenso `#D90429` |
| Navegación y texto principal | Gris antracita `#25272B` |
| Fondo y superficies | Blanco `#FFFFFF` |

Los tintes claros y grises de interfaz sirven para separar secciones y mantener la lectura. El rojo principal mantiene contraste de 5,25:1 sobre blanco. En la navegación antracita, el símbolo va sobre una base blanca para conservar su visibilidad.

**Símbolo elegido para la demo:** [marca ConsultorAI](../assets/consultorai-mark-v1.png). Es el primer concepto generado el 14 de octubre de 2026 y seleccionado por Javi. Representa cuatro barras de impacto dentro de un círculo abierto. El nombre se escribe como texto junto al símbolo. El archivo PNG tiene fondo transparente; puede usarse en la aplicación, el vídeo y documentos de la demo. La marca definitiva para una actividad profesional futura podrá revisarse después del hackatón.

Los [dos prompts exactos de generación](../05-prompts-imagen-marca.md) están guardados para la auditoría del hackatón. Se utilizó la herramienta de generación de imágenes integrada en Codex. Se generó una segunda opción, pero Javi eligió la primera.
